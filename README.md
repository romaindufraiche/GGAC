# G.G.A.C. — refonte

Refonte statique (HTML/CSS/JS sans dépendance) des pages du site du Groupe des Généalogistes Amateurs du Cambrésis.

- `agenda.html` : page Agenda (reprise de https://www.ggac.fr/agenda.php, textes inchangés)
- `index.html` : redirige vers l'agenda

Ouvrir `agenda.html` dans un navigateur. Les animations respectent `prefers-reduced-motion`.
